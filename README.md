# Intro-to-GitHub

## Project Overview
This repository was created as a practical exercise for Assignment #3: Introduction to Git and GitHub. Its primary purpose is to demonstrate basic version control skills, including creating a remote repository, writing Markdown documentation, and managing file uploads. 

## Included Files
As required by the assignment, this repository contains Python scripts I developed for the Steam programming puzzle game *The Farmer Was Replaced*. These files serve as sample code to practice tracking, committing, and managing changes using Git.
